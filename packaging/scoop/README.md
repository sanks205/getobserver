# Scoop Distribution

The manifest in this directory targets the published v0.8.2 Windows binaries and their verified SHA-256 values.

A public bucket requires a separate Git repository, such as scoop-observer, with bucket/observer.json. The Community source folder alone is not a published bucket.

Prepare complete repository files with scripts/prepare-package-repositories.py, then publish and test that repository before documenting the installation as available.

See [distribution trust](../../docs/DISTRIBUTION-TRUST.md).
