# Homebrew Distribution

The formula in this directory targets the published v0.8.2 binaries and their verified SHA-256 values.

A proper public tap requires a separate homebrew-observer repository with Formula/observer.rb. The Community source folder alone is not that tap.

Prepare complete repository files with scripts/prepare-package-repositories.py, then publish and test the separate repository before documenting the installation as available.

See [distribution trust](../../docs/DISTRIBUTION-TRUST.md).
