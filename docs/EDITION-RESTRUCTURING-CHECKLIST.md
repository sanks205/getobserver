# Historical Edition Restructuring Checklist

> This document summarizes the earlier edition restructuring. Its sales model is superseded by [Observer Pro, one annual all-access subscription at $89/year](https://observerly1.gumroad.com/l/observer-pro-offline-code-audit). Current release checks are maintained in [RELEASE-READINESS-CHECKLIST.md](RELEASE-READINESS-CHECKLIST.md).

## Recorded work from the earlier phase

- Inventory Community scanners, reports, dashboard, exports, CI, and offline controls.
- Inventory private Pro reporting, premium rules, scheduling, history review, SBOM, and licensing.
- Preserve Community dashboard history, exports, baselines, changed-code scans, and external automation.
- Document edition boundaries, implementation evidence, and license compatibility risks.
- Centralize private purchase routing and correct inconsistent legacy feature access.
- Add compatibility-focused licensing regression coverage.
- Create the edition matrix, comparison-evidence checklist, and product documentation.

## Outstanding principles

- Historical test results are not evidence for a later release.
- Preserve existing customers' rights and compatibility formats.
- Current Pro feature gates do not represent separately purchasable products.
- Major proposed features require their own validation and implementation review.
- Check links, exact binaries, checksums, and public/private boundaries for each upload.
