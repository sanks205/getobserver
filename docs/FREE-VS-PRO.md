# Observer Community vs Pro

## Product principle

**Community: find and fix problems in your own code.**

**Pro: run deeper professional audits, manage repeat assessments, and create client-ready deliverables.**

Community is intentionally useful and has no repository-size, file-count, finding-count, or account limit.

| Capability | Community | Pro |
|---|:---:|:---:|
| Local scan, technology detection, core security/config/infra checks | Yes | Yes |
| Runtime/log analysis and dependency parsing | Yes | Yes |
| HTML, JSON, CSV, and SARIF | Yes | Yes |
| Dashboard history and issue deltas | Yes | Yes |
| Baselines, changed-code scans, gates, CI, and pre-commit hook | Yes | Yes |
| Offline controls and deterministic remediation guidance | Yes | Yes |
| Premium framework-specific rules | - | With Premium Rules |
| Organization-ready PDF with document control, navigation, remediation plan, and branding | - | With Professional PDF |
| Integrated recurring scans and dashboard scheduler | - | With Scheduled Scans |
| Git-history secret review and CycloneDX SBOM | - | Any paid Pro entitlement |
| HMAC companion for local attestations | - | Professional PDF entitlement |

## Important boundaries

Community can be automated with CI, cron, or Task Scheduler. Pro scheduling sells an integrated local workflow, not exclusive permission to automate. Community HTML can be printed to PDF. Pro sells a structured professional assessment document, not merely a PDF file extension. Both editions use heuristic analysis and optional engines; neither guarantees security or replaces full semantic SAST.
